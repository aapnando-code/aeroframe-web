AEROFRAME.ID Content Manager

Kelola isi Galeri dan Portfolio tanpa menyentuh index.html. Setelah selesai, unduh content.json lalu ganti file tersebut di website.

Galeri

Gunakan path seperti assets/gallery/nama-file.jpg atau URL publik. File media tetap harus tersedia di hosting/cloud Anda.

Portfolio

Gunakan path cover seperti assets/portfolio/project-01.jpg.

Alur update website

1) Simpan foto/video di folder assets/gallery atau assets/portfolio. 2) Buka halaman ini. 3) Masukkan path file, judul, dan deskripsi. 4) Klik Unduh content.json. 5) Upload content.json terbaru ke folder yang sama dengan index.html. Tidak perlu mengedit HTML.
